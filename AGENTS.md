# Работа с Local Medical Archive

Прочитайте ARCHITECTURE.md, PROJECT_SPECIFICATION.md и TASKS.md перед изменениями. Корневая спецификация v1.2 определяет объём; README и docs/VALIDATION.md отражают фактическое состояние.

- Медицинские fixtures только синтетические. Не добавляйте реальные документы, дампы, ключи, индексы или содержательные runtime logs в Git.
- Сохраняйте React/TypeScript + NestJS/TypeORM/PostgreSQL + Python/FastMCP/LangGraph. Изменения контрактов согласуйте между сервисами.
- Архив и публичный MCP различаются жёстко заданным корпусом. Не добавляйте выбор личного корпуса в публичные инструменты, внешние AI API/SDK или автопередачу консультаций. Локальный nginx ingress/host-Ollama proxy не является внешним LLM-gateway.
- MCP выдаёт только очищенные ответы/фрагменты синтетического корпуса: общий компонент правил и локальной LLM, непрозрачные responseRef/S1, локальное соответствие источникам. Не выдавайте исходные названия, пути, documentId/chunkId, произвольные metadata и trace. Ошибка privacy, недоступность модели и прямой запрос PII не разрешают raw fallback. index/status и ошибки содержат только безопасные агрегаты/фиксированные сообщения.
- Медицинские обязательные форматы — PDF с текстовым слоем, TXT и MD; корпус не менее 512000 байт полезного текста. Python, ChromaDB, rank_bm25 и четыре имени tools — выбор проекта. BM25/RRF/Corrective RAG, Ollama, Compose и настоящий MCP сохраняются. Проверяйте сохранность медицинских чисел, единиц, доз, сроков и отрицаний после chunking и очистки.
- Источник факта неизменяемый и версионный. Исправление пользователя не превращайте в цитату PDF. Review hash экспорта относится к точному текущему тексту.
- Миграции явные; production synchronize запрещён. Операции обработки устойчивы к перезапуску и не дублируют данные.
- Проверяйте изменённый слой командами из README. Mock tests и реальные Ollama evaluations — разные доказательства; не подменяйте одно другим.
- Личный REPORT пользователь пишет сам. AI может добавлять только явно помеченные фактические технические записи.
- Сохраняйте реальные небольшие коммиты; не переписывайте начальный архитектурный коммит ради имитации истории.
