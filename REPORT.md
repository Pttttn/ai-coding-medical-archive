### Использованные инструменты и модели

Авторские записи указывают облачный ChatGPT для обсуждения идеи, подготовки спецификации и разбора консультации; Codex — для планирования, реализации и технической проверки; GitHub — для публикации. Точная модель облачного ChatGPT в этих записях не указана.

`qwen 3.8` сохранён в первом запросе как историческая формулировка автора, а не как описание установленной модели. В реализованном приложении используются локальные Ollama **qwen2.5:3b** и **nomic-embed-text**. Отдельная проверка выбора MCP-инструмента reference host использовала **qwen3.5:4b**; это не модель основного RAG и не проверка IDE пользователя.

- Реальная проверка Docker выявила отсутствие опубликованного порта на полностью внутренней сети. Добавлен отдельный ingress gateway с OUTPUT firewall. Первичная загрузка моделей выполнена отдельно от архива; повторный запуск использует имеющиеся веса.
- Реальные прогоны qwen2.5:3b обнаружили ошибки сохранения отрицаний и ответы из общих знаний. Неудачные результаты сохранены. AI-агент усиливает проверку точных цитат; mocks не считаются доказательством качества модели.

- Сквозной сценарий выявил бесконечно длинную генерацию JSON после удаления релевантного документа: Ollama дошёл до 180-секундного timeout. Реальный контроль после удаления теперь возвращает отказ; это не замена сбоя модели успешным ответом.

Маленькая модель остаётся неточной при датированных отрицаниях, обзорных вопросах и выборе всех источников противоречия. Linux AI suite расширен до 59 успешных тестов.
