# Личный отчёт автора

Этот раздел предназначен для личных записей студента. AI не приписывает автору свои решения, чувства, проблемы или несуществующие промпты. Перед сдачей автор должен самостоятельно описать свой опыт и проверить технические приложения.

## Записи автора

_Заполняет автор по мере участия в проекте: решения, использованные инструменты/модели, удачные и неудачные промпты, проверка и исправления._

## Приложение: технический журнал AI (не личный отчёт)

- 2026-09-19: Codex изучил три предоставленных MD-файла. В каталоге не было прикладного кода или Git-репозитория. До кодирования создан ARCHITECTURE.md с границами, выбранным ORM, контрактами и планом.
- Фактический запрос пользователя: «изучи проектную спецификацию и реализуй проектное задание». Анализ: широкая постановка уточнена чтением спецификации v1.1; её ограничения и проверяемые критерии используются для реализации. Это пример реального запроса, а не вымышленная история промптинга.
- Среда: Windows, Node 24, Python 3.11–3.14, Docker CLI. Доступность Docker daemon и конкретных моделей проверяется отдельно; наличие CLI не считается успешным запуском Compose.
