## Независимая серия

На отдельном Compose-проекте с собственным новым томом моделей запущены пять повторов на одном persistent-индексе и три с новыми индексами. Задан `--profile` от предыдущей серии RTX 5080; несовпадение моделей, кода, данных, runtime или параметров запрещает начало оценки. GPU и драйвер описываются отдельно и ожидаемо различаются. Все восемь попыток завершены с кодом серии 0. [Все попытки и оценки](series/series.json), [частоты по вопросам](series/summary.md), [хеш-диагностика](series/analysis.json), [профиль](series/profile.json).

Все четыре новых индекса содержат 773 чанка с одинаковым fingerprint векторов внутри второй машины. В каждой группе 196 повторявшихся одинаковых входов провайдера, без вариантов выхода. Не прошли `overview-01`, `negation-01`, `conflict-01` — каждый по 0/8; эталоны не менялись.

### Что воспроизвелось между компьютерами

[Расчёт сравнения](cross-machine.json) использует первый запуск RTX 5080 как эталон для всех восьми запусков RTX 5060 Ti: 168 сравнений вопросов. Профили полностью равны, итог PASS/FAIL совпал во всех 168 сравнениях. Таким образом, на этих двух стендах воспроизвелись качество **18/21** и частоты по каждому вопросу.

Побитовое совпадение всей работы не подтвердилось. В 13/21 вопросах каждого запуска (104/168 сравнений) различаются хеши вызовов или этапов. В том числе провайдер даёт разные выходы при одинаковых входах. Fingerprint сохранённых embedding-векторов отличается между машинами. Проверенная публичная выдача отличается только у `overview-01` — в 8/168 сравнениях; этот вопрос не прошёл на обеих машинах. Для остальных 20/21 вопросов хеш публичной выдачи совпал (случайный responseRef исключён).

Это измерение двух сочетаний GPU/драйвера/host OS, без выделения влияния каждого фактора. Оно не гарантирует результат на CPU/Mac, других моделях или отсутствие редких сбоев. Полная повторная CPU-серия здесь не выполнялась: стандартный CPU Compose проверен сценариями приложения выше. Успешная установка и стабильные 18/21 не означают исправления трёх ошибок качества.

Точные команды независимой серии (из того же чистого clone; обязательна настроенная поддержка NVIDIA в Docker):

```sh
mkdir -p .local-evaluation
cp docs/evaluation/stability-2026-09-22/after/profile.json .local-evaluation/reference-5080-profile.json
docker compose -p lma-mpc6-eval -f compose.evaluation.yaml -f compose.evaluation.cuda.yaml up -d --wait --wait-timeout 1800 ollama
docker compose -p lma-mpc6-eval -f compose.evaluation.yaml -f compose.evaluation.cuda.yaml run --rm --build evaluator --execution gpu --profile /results/reference-5080-profile.json --output-dir /results/mpc6-cuda-01
docker compose -p lma-mpc6-eval -f compose.evaluation.yaml run --rm --no-deps --entrypoint python evaluator scripts/analyze_stability.py /results/mpc6-cuda-01
```

Каталог результата должен быть новым. Здесь приложение и evaluator используют разные Compose-проекты и тома. Если будущая пересборка изменит версии runtime или digests весов, строгий профиль отклонит опыт; это нельзя обходить молчаливой подменой эталона. Новый профиль означает отдельно обозначенный эксперимент.
