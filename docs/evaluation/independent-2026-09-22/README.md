## Независимая серия

На отдельном Compose-проекте с собственным новым томом моделей запущены пять повторов на одном persistent-индексе и три с новыми индексами. Задан `--profile` от предыдущей серии RTX 5080; несовпадение моделей, кода, данных, runtime или параметров запрещает начало оценки. GPU и драйвер описываются отдельно и ожидаемо различаются. Итог серии будет добавлен после всех восьми попыток.

[Команды и правила подсчёта](../STABILITY.md), [предыдущая серия](../stability-2026-09-22/README.md). Индексы, векторы и содержательные runtime logs в Git не включаются. Приложение на второй машине доступно только через loopback; для ручного просмотра можно использовать SSH port forwarding.
