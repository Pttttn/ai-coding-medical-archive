## Изменения и обнаруженные ошибки

Корпус теперь содержит 42 файла MD/TXT/PDF: 663711 файловых байт, из них 661410 байт обычного индексируемого текста, достаточных для порога 512000 без PDF overhead. Manifest проверен по рабочим файлам и по Git blobs после нормализации LF. Seed по-прежнему 36 записей, неизменяемые источники и 5 исправлений. Реальная миграция MCP-индекса: 45/777 → 42/773 (файлы/чанки), удалены 5 запрещённых форматов. Последующие index_folder ничего не дублируют.

Публичные поля ограничены очищенным текстом, reference S1/S2 и случайным responseRef. Локальная таблица соответствий не доступна через MCP. Весь сериализованный ответ проверяется, включая ошибки. Проверены недоступность модели, неверный JSON, неизвестные поля, несуществующие spans, числовые коллизии, единицы, даты, отрицания и неизвестность приёма. Цитаты собираются структурно, поэтому медицинские [17]/[1] не превращаются в номера ссылок.

Реальная модель выявила проблемы сверх тестовых адаптеров: подстановка частей имени ломала email до его удаления; имя после fictional participant не очищалось; адрес 15 Pine Street ошибочно считался числом с единицей. Исправлены порядок обработки, общий шаблон narrative name-cue и проверка адресов. Неудачные попытки сохранены: [email](evaluation/v12-public-rag-before-email-order.json), [имя без метки в MCP](evaluation/v12-mcp-http-before-name-cues.json), [ложный отказ адреса](evaluation/v12-manual-privacy-before-address-guard.json). Старые privacyPassed flags отражают набор проверок на момент запуска, а не итоговое отсутствие утечек.

## Известные ограничения

Не прошли совместную текущую RAG-проверку: **overview-01, multi-01, negation-01, conflict-01**. Обзор выбирает слишком узкий источник; вопрос о двух визитах и отдельный вопрос о неизвестном приёме могут получить ложный отказ; противоречие Spruce не подтверждается полным ожидаемым набором источников и блокируется строгой privacy-проверкой. Эти случаи сохранены, а не исключены из знаменателя.

Метрика проверяет заданный текст, нужные источники, ожидаемый отказ и известные вымышленные идентификаторы. Она не измеряет медицинскую правильность и не доказывает полную анонимность. Ручной preview/hash остаётся обязательным для личного экспорта. MCP автоматически передаёт очищенную синтетику host-агенту; доступ к личному корпусу и внешние AI SDK не добавлены.

Новая дата защиты и согласование собственной темы не подтверждены. Личную часть REPORT пишет автор. Reference host действительно использует MCP, но не заменяет проверку конкретного IDE пользователя.
